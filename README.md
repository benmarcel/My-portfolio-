# My-portfolio-
Chima Ben - Personal Portfolio [(https://benmarcel.github.io/My-portfolio-/)]

A dynamic and responsive personal portfolio website showcasing my skills, projects, and professional background as a Web Designer & Developer. This site is designed to provide a seamless user experience across all devices, highlighting my expertise in creating clean, intuitive, and high-performing digital experiences.

## Features
- Responsive Design: Optimized for seamless viewing on desktops, tablets, and mobile devices.

- Intuitive Navigation: Clear and easy-to-use navigation bar with smooth scrolling to sections.

Dynamic Mobile Menu: A clean, collapsible hamburger menu for mobile users.

- Hero Section: An engaging introduction and social links.

- About Me: Detailed section outlining my professional journey, interest, and personal information.

- Projects Showcase: A dedicated section to display key projects with brief descriptions and links.

- Skills Section: Visual representation of my technical proficiencies with progress bars.

- Contact Form: A direct way for visitors to get in touch with me.

- Accessibility Conscious: Implemented with considerations for color contrast, semantic HTML, and ARIA attributes.

- Modern Aesthetics: Clean and professional design leveraging modern CSS frameworks.

## Tech stack
* HTML5: For the core structure of the web pages.

* Tailwind CSS: A utility-first CSS framework for rapid and responsive UI development.

* Font Awesome: For scalable vector icons.

## Getting Started
These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites
You need a web browser to view the site. For local development, a code editor (like VS Code) is recommended.

### Installation

* clone the repository:
```bash
    git clone "https://github.com/benmarcel/My-portfolio-.git"
```
* Navigate to project directory
```bash
    cd My-portfolio
```

### Open in your browser:
Simply open the index.html file in your preferred web browser. You can usually do this by double-clicking the file.

## Usage
Navigate through the portfolio using the header links or by scrolling down the page. Each section is clearly defined:

HOME: Introduction and quick overview.

ABOUT: Learn more about my background and interests.

PROJECTS: Explore my past works and case studies.

SKILLS: See my technical proficiencies.

CONTACT: Reach out for inquiries or collaborations using the form provided.
